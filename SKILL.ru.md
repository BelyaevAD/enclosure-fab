# enclosure-fab

Дополнительный текст. Клиенты Cursor, Claude и Codex читают [SKILL.md](SKILL.md) на английском и этот файл сами не подключают.

Править YAML-спеку и закоммиченный шаблон. 3MF открывает человек в слайсере.

- Миллиметры в спеке — это деталь. Шаблон добавляет зазор.
- `preview` можно при неподтверждённых полях. Первая строка ответа — `NOT_FOR_PRINT`. Имя файла начинается с `PREVIEW-`.
- `print` только после подтверждения fit-critical. Пересечение keep-out — файла нет.
- `usb.offset_mm.z` — центр кожуха разъёма от низа платы.
- Копировать фикстуру (`demo_rect`, `demo_round`, `demo_shell`, `demo_tray`), а не выдумывать шаблон.
- Не писать сырой CadQuery в чат. Не запускать печать. Не открывать слайсер.
- Интерпретатор — CPython 3.12. Не поднимать venv голым `python`, если это 3.13.
- Не запускать `pip install -U`.
