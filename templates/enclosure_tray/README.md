Template `enclosure_tray` is implemented in [`fabkit/enclosure_tray.py`](../../fabkit/enclosure_tray.py).

Tray for several devices with an open well (pattern `device-tray`). Example: `fixtures/demo_tray.yaml`. The lid is a separate part. Auto print-pose is not implemented: rotate parts in the slicer. Not `enclosure_snap`. Overlay patches are forbidden.
