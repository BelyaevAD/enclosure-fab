enclosure-fab

A short YAML file describes the enclosure. You get STL, 3MF, STEP, and a picture of the part. Open the 3MF in a slicer yourself. Nothing here is sent to a printer.

View source Install
CPython 3.12 Draft, not a print MIT

How it works

The shape comes from a template in the repo. Change the numbers in YAML instead of writing a script for each part.

Draft first

You can build a file before the sizes are checked. The name starts with PREVIEW-. Do not print that file yet.

Then print

print runs only after the sizes that decide the fit are confirmed. If the part crosses a keep-out, no file is written.

Then the slicer

The 3MF is the shape only, with no slicer settings. Turn the lid yourself if it is lying the wrong way.

Examples

The numbers are made up. Copy a file and put in your own measurements. These are not a real device.

demo_rectRectangular box, connector opening on +X
demo_roundCylinder, separate lid, six holes
demo_shellShell around a device outline
demo_trayTray with an open bay and a separate lid

Install

Python 3.12

CadQuery 2.8 needs Python 3.12. Do not run pip install -U. VTK, Numba, and NumPy would upgrade with it, and the preview can change.

Full install
powershell 
git clone https://github.com/BelyaevAD/enclosure-fab.git
cd enclosure-fab
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\fab.py preview fixtures\demo_round.yaml
