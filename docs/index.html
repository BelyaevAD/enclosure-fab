enclosure-fab

A short YAML spec becomes STL, 3MF, and STEP. A preview image shows the part. You open the 3MF in a slicer. This program does not talk to a printer.

View source Install
CPython 3.12 Preview is not a print MIT

What it is for

The solid comes from a committed template. You change numbers in YAML. You do not paste a one-off script into the chat.

Preview first

Unconfirmed millimetres are allowed. The file name starts with PREVIEW-. That file is not a release for the printer.

Print is a gate

print runs only after fit-critical fields are confirmed. If the keep-out solid hits the part, the mesh is not written.

You slice it

Open the 3MF and load geometry only. CadQuery does not write slicer project settings. Rotate the lid yourself if the advice pose is wrong.

Examples in the repo

Synthetic parts with made-up sizes. Copy a fixture and change the numbers. They are not measurements of a real device.

demo_rectRectangular box, USB-sized opening on +X
demo_roundCylinder, separate lid, six vent holes
demo_shellShell around a device envelope
demo_trayTray, open well, separate lid

Install

Python 3.12

CadQuery 2.8 is pinned to that interpreter. Do not pip install -U the stack. VTK, Numba, and NumPy move together.

All four commands
powershell 
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\fab.py preview fixtures\demo_round.yaml
