enclosure-fab

Короткий YAML описывает корпус. На выходе STL, 3MF, STEP и картинка детали. В слайсер файл открываешь сам: на принтер ничего не уходит.

Исходный код Установка
CPython 3.12 Черновик — ещё не печать MIT

Как это устроено

Форму собирает шаблон из репозитория. В YAML меняешь размеры. Отдельный скрипт под каждую деталь не нужен.

Сначала черновик

Пока размеры не проверены, файл всё равно можно собрать. Имя начинается с PREVIEW-. Печатать его рано.

Потом печать

print запускается, когда размеры посадки уже подтверждены. Если деталь залезла в запрещённую область, файла не будет.

Дальше слайсер

В 3MF только форма, без настроек слайсера. Если крышка лежит не так, поворачиваешь её сам.

Примеры

Размеры в примерах придуманы. Скопируй файл и подставь свои: это не обмер настоящего прибора.

demo_roundЦилиндр, отдельная крышка, шесть отверстий
demo_shellКожух по габариту устройства
demo_trayЛоток с открытым отсеком и отдельной крышкой

Установка

Python 3.12

Пакеты CadQuery 2.8 ставятся на Python 3.12. Не запускай pip install -U: VTK, Numba и NumPy обновятся следом, и картинка предпросмотра может измениться.

Вся установка
powershell 
git clone https://github.com/BelyaevAD/enclosure-fab.git
cd enclosure-fab
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\fab.py preview fixtures\demo_round.yaml
