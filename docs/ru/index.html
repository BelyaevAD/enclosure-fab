Зачем

Тело пишет закоммиченный шаблон. Меняются числа в YAML. Отдельный скрипт в чат не вставляют.

Сначала preview

Неподтверждённые миллиметры допустимы. Имя файла начинается с PREVIEW-. Это не выпуск на принтер.

Print — отдельный гейт

print идёт только после подтверждения fit-critical. Если keep-out пересекает деталь, файла нет.

Слайсер вручную

3MF открывают как геометрию. Настройки проекта слайсера файл не содержит. Крышку поворачивают сами.
