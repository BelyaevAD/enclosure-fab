enclosure-fab

YAML-спека становится STL, 3MF и STEP. Картинка показывает деталь. 3MF открывают в слайсере. Программа с принтером не говорит.

Исходный код Установка
CPython 3.12 Preview — не печать MIT

Зачем

Тело пишет закоммиченный шаблон. Меняются числа в YAML. Отдельный скрипт в чат не вставляют.

Сначала preview

Неподтверждённые миллиметры допустимы. Имя файла начинается с PREVIEW-. Это не выпуск на принтер.

Print — отдельный гейт

print идёт только после подтверждения fit-critical. Если keep-out пересекает деталь, файла нет.

Слайсер вручную

3MF открывают как геометрию. Настройки проекта слайсера файл не содержит. Крышку поворачивают сами.

Примеры в репозитории

Синтетические детали. Размеры выдуманы. Это не обмер живого прибора.

demo_rectПрямоугольная коробка, окно под USB на +X
demo_roundЦилиндр, отдельная крышка, шесть отверстий
demo_shellКожух вокруг габарита прибора
demo_trayЛоток, открытый колодец, отдельная крышка

Установка

Python 3.12

Колёса CadQuery 2.8 стоят на этом интерпретаторе. Не запускайте pip install -U. VTK, Numba и NumPy уезжают вместе.

Вся установка
powershell 
git clone https://github.com/BelyaevAD/enclosure-fab.git
cd enclosure-fab
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\fab.py preview fixtures\demo_round.yaml
